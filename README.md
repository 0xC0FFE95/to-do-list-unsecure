# to-do-list app

<br>
<br>

> ⚠️ **WARNING - NE JAMAIS DEPLOYER EN PRODUCTION** ⚠️
>
> Cette application est **volontairement truffée de failles de sécurité** dans un cadre
> **pédagogique uniquement** (démo d'analyse SonarQube, de SCA et d'exploitation de vulnérabilités
> OWASP : XSS, injection SQL, CSRF, désérialisation, dépendances CVE, etc.).
> Elle ne doit **jamais être exposée en production** ni exécutée sur un réseau non maîtrisé.
